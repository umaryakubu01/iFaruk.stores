Place your product photography, hero images, and brand imagery in this folder
(or reference hosted image URLs directly in the admin panel for products).

Suggested files to add here for the static <img> placeholders already wired
up in the HTML:
  - hero-watch.jpg        (homepage hero)
  - brand-story.jpg       (homepage "Our Story" section)
  - about-hero.jpg        (about.html)
  - contact-boutique.jpg  (contact.html)
  - category-*.jpg        (category showcase thumbnails)

Product images themselves are managed through the admin panel (Products →
Add/Edit Product → Image URLs) and are expected to be hosted image URLs
(e.g. Cloudinary, S3, Imgur) rather than files stored in this folder.
